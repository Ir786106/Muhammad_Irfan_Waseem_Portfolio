# Current design audit

The original homepage used a split layout, cyan role accents and a three-ring sculpture beside a short heading. The focal point competed with the copy instead of bringing both into one composition. Featured projects repeated the same card treatment, and the footer and contact section felt disconnected from the hero. The original browser evidence is available in [desktop](screenshots/desktop.png) and [mobile](screenshots/mobile.png).

The redesign keeps the project catalog and individual routes, theme preference, contact integration and résumé downloads. Its main changes are a single stage for the name and sculpture, larger alternating project features and a portrait-led biography.
