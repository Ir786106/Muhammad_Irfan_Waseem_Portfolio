## ✨ Key Features

This portfolio is a fully functional web application integrated with backend services and advanced front-end animations:

* 🌓 **Dynamic Theme Toggle:** Seamless Dark and Light mode switching with local storage memory.

* ✨ **Premium Animations:** High-performance scroll animations, magnetic buttons, and a custom mouse cursor powered by **GSAP & ScrollTrigger**.

* 🔥 **Live Testimonials (Firebase):** A real-time feedback system. Users can securely log in via Google Authentication, leave a star rating, and update their review within a 24-hour window.

* 📱 **Mobile-Safe & Responsive:** Flawless rendering across all devices. Complex animations are safely optimized for mobile devices to ensure peak performance.

* 📧 **Functional Contact Form:** Direct email routing via **Formspree** alongside a Firebase Firestore database backup.

* 🎨 **Glassmorphism UI:** Modern frosted-glass aesthetics with custom grid-background animations.
