## ✨ Key Portfolio Features

* 🌓 **Dynamic Theme Toggle:** Instant switching between Dark and Light modes with seamless CSS variable transitions and `localStorage` persistence.
* 🎨 **Glassmorphism UI:** Modern frosted-glass aesthetic, custom mesh-grid gradients, and responsive layouts.
* 🌀 **3D Interactive Showcase:** Integrated **Three.js** canvas rendering real-time interactive geometry responding to mouse movements.
* ✨ **GSAP & ScrollTrigger Animations:** High-performance scroll-driven animations, magnetic interactive buttons, and custom cursor tracker.
* 🔥 **Live Firebase Testimonials:** Real-time feedback system powered by **Google Firebase Auth** and **Cloud Firestore**, allowing verified Google accounts to leave ratings and edit reviews within a 24-hour window.
* 📱 **Fully Responsive Design:** Mobile-first architecture with dedicated mobile navigation drawer, fluid typography, and touch-optimized controls.
* 📧 **Contact & Lead Capture:** Direct email handling via **Formspree** with Firestore database backup.
* ⚡ **Built-in Local Development Server:** Zero-dependency Node.js HTTP server (`serve.js`) supporting complete MIME types and clean routing.

* **Markup & Structure:** Semantic HTML5 with accessibility considerations

## 🚀 Getting Started (Local Development)

### Prerequisites
* A modern web browser (Google Chrome, Edge, Firefox, Safari)
* Optional: [Node.js](https://nodejs.org/) (v14 or later) to run the included development server

### 1. Clone the Repository
```bash
git clone https://github.com/Ir786106/Muhammad_Irfan_Waseem_Portfolio.git
cd Muhammad_Irfan_Waseem_Portfolio
```

### 2. Run Locally

#### Option A: Using the built-in Node.js server (Recommended)
```bash
node serve.js
```
Then navigate to: `http://localhost:8080`

#### Option B: Using VS Code Live Server or any static server
* Open the directory in VS Code and click **"Go Live"** via the Live Server extension, or:
```bash
npx serve .
```

#### Option C: Direct Browser Preview
* Double-click `index.html` to open it directly in your favorite browser.
